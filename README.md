## 📋 Project Overview

This project implements a comprehensive **6-stage audio restoration pipeline** designed to enhance the quality of audio generated by generative models like MusicGen. The pipeline addresses common issues in AI-generated audio:

- 🎵 Low bit depth and quantization artifacts
- 🔊 Background noise and unwanted vocal interference
- 📉 Reduced dynamic range and frequency resolution
- ✨ Lack of clarity and professional polish

## 🎯 Key Features

### Multi-Stage Processing Pipeline

1. **Targeted Denoising** - Removes unwanted vocal artifacts while preserving instrumental content
2. **De-clipping** - Repairs audio distortion from signal clipping
3. **Adaptive Filtering** - Frequency-selective noise removal based on spectral analysis
4. **Spectral Subtraction** - Advanced noise reduction technique
5. **Clarity Enhancement** - Multi-band EQ for improved presence and definition
6. **Final Polish** - Professional normalization and dithering

## 🔧 Usage

### Basic Usage
```python
from audio_restorer import AggressiveAudioRestorer

# Initialize the restorer
restorer = AggressiveAudioRestorer(sample_rate=44100, verbose=True)

# Restore an audio file
restorer.restore('input.wav', 'output_restored.wav')
```

### Advanced Usage
```python
import librosa
import soundfile as sf

# Load audio
audio, sr = librosa.load('input.wav', sr=44100, mono=True)

# Apply individual stages
audio = restorer.aggressive_denoise(audio)
audio = restorer.declip(audio)
audio = restorer.adaptive_filtering(audio)
audio = restorer.spectral_subtraction(audio)
audio = restorer.enhance_clarity(audio)
audio = restorer.final_polish(audio)

# Save result
sf.write('output.wav', audio, sr)
```

## 📊 Pipeline Architecture
```
┌─────────────────┐
│   Input Audio   │
│   (Low Quality) │
└────────┬────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  Stage 1: Targeted Denoising        │
│  - STFT analysis (200-4000 Hz)      │
│  - Voice artifact detection         │
│  - Median filtering                 │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  Stage 2: De-clipping               │
│  - Detect clipped samples           │
│  - Interpolate from clean samples   │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  Stage 3: Adaptive Filtering        │
│  - Spectral analysis                │
│  - Frequency-selective removal      │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  Stage 4: Spectral Subtraction      │
│  - Noise profile estimation         │
│  - Aggressive oversubtraction       │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  Stage 5: Clarity Enhancement       │
│  - Multi-band EQ                    │
│  - Sub-bass: 0.2x (20-60 Hz)        │
│  - Bass: 0.5x (60-250 Hz)           │
│  - Mids: 1.5x (250-4000 Hz)         │
│  - Highs: 1.8x (4000-16000 Hz)      │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  Stage 6: Final Polish              │
│  - Soft clipping (tanh)             │
│  - Peak normalization (-0.5 dB)     │
│  - Triangular dithering             │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────┐
│  Output Audio   │
│ (Enhanced/Clean)│
└─────────────────┘
```

## 🛠️ Technical Details

### Processing Specifications

| Parameter | Value |
|-----------|-------|
| Sample Rate | 44,100 Hz |
| Bit Depth | 24-bit (output) |
| STFT Window | 2048 samples |
| Hop Length | 512 samples |
| Voice Band | 200-4000 Hz |
| Output Format | WAV (PCM_24) |

| Band | Frequency Range | Weight |

| Bass | 60-250 Hz | 0.5× |
