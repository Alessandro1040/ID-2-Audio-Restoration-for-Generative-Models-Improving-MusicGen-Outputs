## 🎯 Project Overview

This project implements a **6-stage audio restoration pipeline** to enhance the quality of audio generated by AI models like MusicGen.

### Problems Solved:
- 🎵 **Quantization artifacts** in AI-generated audio
- 🔊 **Background noise** and unwanted vocal interference  
- 📉 **Reduced dynamic range** and frequency content
- ✨ **Lack of professional polish** in synthesized audio

### Solution:
A zero-shot post-processing pipeline combining:
- Targeted denoising using STFT analysis
- Multi-band spectral enhancement
- Professional normalization and dithering

## 🔧 How It Works

### Pipeline Architecture
```
┌─────────────┐
│ Input Audio │  (Low quality, noisy)
└──────┬──────┘
       │
       ▼
┌──────────────────────────────┐
│ Stage 1: Targeted Denoising  │  Remove vocal artifacts
└──────┬───────────────────────┘
       │
       ▼
┌──────────────────────────────┐
│ Stage 2: De-clipping         │  Repair distortion
└──────┬───────────────────────┘
       │
       ▼
┌──────────────────────────────┐
│ Stage 3: Adaptive Filtering  │  Frequency-selective cleanup
└──────┬───────────────────────┘
       │
       ▼
┌──────────────────────────────┐
│ Stage 4: Spectral Subtraction│  Noise profile removal
└──────┬───────────────────────┘
       │
       ▼
┌──────────────────────────────┐
│ Stage 5: Clarity Enhancement │  Multi-band EQ boost
└──────┬───────────────────────┘
       │
       ▼
┌──────────────────────────────┐
│ Stage 6: Final Polish        │  Normalize & dither
└──────┬───────────────────────┘
       │
       ▼
┌─────────────┐
│Output Audio │  (Clean, professional)
└─────────────┘
```

### Technical Details

| Component | Specification |
|-----------|--------------|
| Sample Rate | 44,100 Hz |
| Output Format | 24-bit WAV |
| STFT Window | 2048 samples |
| Voice Band Detection | 200-4000 Hz |

**Multi-Band EQ Weights:**
- Sub-bass (20-60 Hz): **0.2×** (reduce rumble)
- Bass (60-250 Hz): **0.5×** (maintain foundation)
- Mids (250-4000 Hz): **1.5×** (enhance clarity)
- Highs (4000-16000 Hz): **1.8×** (add presence)

## 💻 Usage Example
```python
from audio_restorer import AggressiveAudioRestorer

# Initialize
restorer = AggressiveAudioRestorer(sample_rate=44100, verbose=True)

# Restore audio file
restorer.restore('noisy_input.wav', 'clean_output.wav')

# Done! Check clean_output.wav
```
